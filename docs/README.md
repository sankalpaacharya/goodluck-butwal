# Website docs

You own this site. These notes let you run it end to end. Start at the top.

| # | File | What it is |
|---|---|---|
| 1 | `accounts-checklist.md` | Every account and key the site needs, in one table |
| 2 | `setup-local.md` | Run the site on your own computer |
| 3 | `setup-production.md` | Put the site live (Vercel) + update the live database |
| 4 | `domain.md` | Connect your web address |
| 5 | `first-login.md` | Admin accounts: the first one, the rest, password resets |
| 6 | `backups.md` | One-time backup setup (R2 + GitHub secrets), then it runs itself |
| 7 | `database-neon.md` | The database: where it lives, dev vs live |
| 8 | `cloudflare-turnstile.md` | The "I am human" check on the forms |
| 9 | `resend-email.md` | The emails the site sends |
| 10 | `cloudinary-media.md` | Images and videos |
| 11 | `google-seo.md` | Google search, verification, visitor stats |
| 12 | `daily-use-admin.md` | Day to day: change text, photos, news, team |
| 13 | `when-something-breaks.md` | Something is wrong: what to do first |

Rule for all of it: secrets go in settings pages, never in chat, email, or code.
