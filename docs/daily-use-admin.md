# Daily use (admin)

Sign in at `/admin/login`. Five wrong passwords in 15 minutes locks you out for a while. Wait, or ask an admin.

| I want to... | Go to |
|---|---|
| Add staff, change a bio or photo | Team |
| Add a partner logo | Partners |
| Add a visa grant graphic | Success stories |
| Quote a Google review | Client reviews |
| Write or publish news | News |
| Add an event, see registrations | Events |
| Add an institution or gallery | Institutions |
| Add courses | Courses |
| Add IELTS/PTE batch, fees, seats | Test preparation, then Batches |
| Upload or replace a picture/video | Images / Videos |
| Answer enquiries | Enquiries |
| Confirm a consultation | Consultations |
| Add a staff login | Users (Admin only) |
| Change Google stars or review count | Settings |

Rules that surprise people:

- A change shows on the site within 5 minutes. Normal, not broken.
- Draft means hidden. Publish means live. There is no scheduling.
- Every image needs alt text (one sentence describing the picture) or publishing is refused.
- Deleting usually means archiving. Archived stays in the admin, so mistakes undo in a minute.
- Page wording, services, destinations, office details: not in the admin. Ask a developer.

Batch labels (Open, Filling fast, Full) follow the seats left. You never set them by hand.
